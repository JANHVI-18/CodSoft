# CodSoft Internship - Selected Projects

## 1. **ATM Interface 🏧**

### Description:
The **ATM Interface** is a simulation of a banking system where users can perform basic banking operations, such as withdrawing money, depositing funds, and checking their account balance. This project mimics the functionality of a real-world ATM system.

### Key Features:
- **User Authentication 🔒**: Users must log in with a valid username and password.
- **Deposit & Withdrawal 💵**: Users can deposit money into their account and withdraw funds.
- **Balance Check 💳**: Displays the current balance of the user’s account.
- **Simple and Clean UI 🎨**: The user interface is simple to use with clear options and easy navigation.

### Technologies Used:
- **Java**: Core Java programming for the logic and application development.
  
### What I Learned:
- Learned how to implement basic banking operations using Java.
- Gained experience in managing user input and controlling program flow based on user actions.
- Developed a secure and intuitive user interface for an ATM simulation.

## 2. **Number Game 🎮**

### Description:
The **Number Game** is a fun and interactive game where the user needs to guess a randomly generated number within a given range. The game gives feedback on whether the guess is too high or too low, and the user tries to guess the correct number in the fewest attempts.

### Key Features:
- **Random Number Generation 🔢**: The game generates a random number within a specified range.
- **Guess Feedback 🗣️**: After each guess, the user receives feedback whether the guess is higher or lower than the target number.
- **Attempt Counter ⏱️**: Tracks the number of attempts taken by the user to guess the correct number.
  
### Technologies Used:
- **Java**: Core Java for handling logic and game flow.
  
### What I Learned:
- Enhanced problem-solving skills by designing an interactive game.
- Worked with random number generation and user input validation.
- Gained experience in keeping track of user progress through the game (attempt counter).

## 3. **Tic-Tac-Toe Game ✖️⭕**

### Description:
The **Tic-Tac-Toe Game** is a classic 2-player game, where players take turns to mark X or O on a 3x3 grid. The goal is to get three of the same marks in a row, column, or diagonal.

### Key Features:
- **Two-player Mode 🤝**: Players take turns to make moves.
- **Win Detection 🏆**: The game automatically detects a win or a tie after each move.
- **Simple and Fun Interface 🎮**: The game has a clean and interactive grid for players to make their moves easily.

### Technologies Used:
- **Java**: Used for implementing the game logic and handling player inputs.
  
### What I Learned:
- Gained experience in implementing game logic such as win detection and turn-based actions.
- Improved skills in managing user input and creating an interactive interface.
- Understood the importance of maintaining state in a multiplayer game.
